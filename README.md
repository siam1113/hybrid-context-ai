# Hybrid Context AI

Production foundation for a hybrid Context-Compiled AI QA platform. The system favors compiled application context, semantic UI memory, reusable flow graphs, deterministic Playwright execution primitives, semantic validation, and targeted LLM reasoning for planning, ambiguity, recovery, and unknown flows.

## Quick start

```bash
npm install
npm run check
```

Infrastructure definitions live in `infrastructure/docker/docker-compose.yml` for PostgreSQL, Redis, Qdrant, Neo4j, Temporal, OpenTelemetry Collector, Prometheus, and Grafana.
